02

How it is built

Three tests with equal weights, each with its own number of tasks. Every task is attempted three times, and what counts is how often it succeeds on the first try: one lucky attempt is not enough.

04

The cache is not a detail

On an agent that rereads the same instructions at every step, the cache decides the bill. The rules change from provider to provider and have to be read before choosing.

ReadA tenth of an input token’s price (Anthropic)
Write, 5 minA quarter more than an input token’s price
Write, 1 hourTwice an input token’s price
ConsequenceA badly written agent pays for the cache on writes and never uses it on reads

05

How I choose

There is no best model. There is the right model for that step, and the choice is made again when the numbers move.

Frontier model

Steps that decide: planning, verification, review
Tasks where a silent error costs more than the token
Work on repositories and the terminal

Cheap or local model

Sorting, extraction, rewriting, classification
High volumes with automatic verification downstream
Data that must not leave the machine

Stated limit

These numbers have a date: they are the photograph of 21 August 2026. A ranking read six months from now says something else, and anyone quoting it without a date is selling an old decision. The values sit in a single file next to the site, and an automatic check compares the page against that file: if the two drift apart, the check turns red and the page is not published.
