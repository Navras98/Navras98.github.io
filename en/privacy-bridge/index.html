Privacy Bridge

Personal data never reaches the model

A desktop application that takes personal data out before the text reaches a model, and puts it back into the reply. The mapping table stays on the machine. Tuned for Italian.

01

How it looks at work

The person writing works as usual. Substitution and restoration happen on the machine: the model receives placeholders, the reply comes back readable.

Write the payment reminder for Mario Rossi, via Palermo 14, invoice 2026-013 overdue since 21 August
3 ITEMS REPLACED · NOME_1 · INDIRIZZO_1 · DOC_1
the text with the placeholders goes to the model 3 s
Draft ready on the anonymised text: firm tone, four lines, no personal data out of the machine.
PUT BACK · Mario Rossi · via Palermo 14 · 2026-013
The reminder is readable and complete. The table matching data to placeholders never left the computer.

The model worked on NOME_1. The person writing read Mario Rossi.

02

The three steps

Nothing to configure for the person writing: the application sits between the keyboard and the model.

OneRecognises and replaces, locally
TwoSends only the text with the placeholders
ThreePuts the data back into the reply, locally

03

Where each thing sits

The boundary is physical, not a promise written into the terms of use.

Stays on your machine

Name, address, VAT number, tax code
The mapping table
The original text and the restored one

Goes out to the model

The text with the placeholders
The structure of the request
No data traceable to a person

04

Why it’s tuned for Italian

Italian names, addresses, VAT numbers and tax codes have shapes of their own. A generic recogniser misses a share of them, and the ones it misses are exactly the ones that must not get out.

FormatsTax code, VAT number, IBAN
AddressesStreet, number, postcode, municipality
NamesItalian registry names, not transliterated

The point

The client’s data stays the client’s.

Stated limit

No substitution system recognises everything: a name written in an unusual way can slip through. Where the risk is high a human read is needed before sending, and the program makes that read quick instead of making it unnecessary.
