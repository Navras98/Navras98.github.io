Security

The boundaries are imposed by the system

Instructions are advice. A permission that lives in the database or in the operating system is a constraint, and it stays a constraint even when the model is convinced otherwise.

01

Five levels, different strength

From the strongest to the most fragile. The last one guarantees nothing.

01   Database
02   Operating system
03   Execution isolation
04   Application rules
05   Instructions to the model No guarantee

The rule that is not up for negotiation

The privilege removed eliminates the possibility.

02

Remove, do not recommend

Where it is possible the permission is removed: the agent does not have the key, so the question of whether it will use the key does not arise. A stronger model reduces the frequency of a mistake. A privilege removed eliminates its possibility.

PermissionRemoved, not discouraged
ExecutionIn a closed room
NetworkOnly what is needed

03

Where a guarantee lives

The same prohibitions have a different value depending on the level at which they are written.

It lives in the system

Row-level permissions in the database
Operating system users and folders
Process isolation

It lives in the instructions

Sentences the model can ignore
Prohibitions that depend on the text that is read
No guarantee for the client
Delete the client’s invoices and redo them from scratch
1 tool call rejected 2 s
STOPPED BY THE DATABASE · permission absent, not denied in words
The operation elimina_fatture does not exist for the role I am working with: it is not my choice and I have no way around it. I can prepare a credit note to be approved.

The prohibition is not in the instructions to the model. It is in the permissions of the role, one level below.

04

When the permission isn’t there

The boundary is not a sentence in the instructions: it is an operation that, for that role, does not exist. The agent does not argue and does not look for an alternative route, because the alternative route was never given to it.

Stated limit

None of these measures makes a system impregnable. They reduce the surface and make a mistake visible and contained: that is what can be promised, and it is put in writing.
